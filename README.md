# AI Vision Studio WEB

Render uchun tayyor Node.js web-app.

## Render
1. Repo'ni GitHub'ga yuklang.
2. Render -> New -> Web Service -> repo'ni tanlang.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Environment Variables ichida `GEMINI_API_KEY` ni kiriting.
6. `GEMINI_MODEL=gemini-3.8-flash` (ixtiyoriy, render.yaml allaqachon beradi).
7. Deploy tugagach `https://...onrender.com` link olinadi.

API key frontendga berilmaydi.
